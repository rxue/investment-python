# TWR
## Daily Return Series calculation
In a real portfolio, there might not be transactions every day, but as to those days without any transactions, their day returns should be calculated anyway. Therfore, price in EURO, i.e. the report currency, on weekdays must be calculated and, in case of price other than EURO, the fx rate should be fetched anyway
